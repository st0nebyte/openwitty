# OpenWitty brand assets

Scalable SVG versions of the OpenWitty O/W soundwave concept.

- `icons/openwitty.svg`: transparent app icon master (white W)
- `icons/openwitty-dark.svg`: icon on dark background
- `github/openwitty-banner.svg`: README project banner

Color: `#97C21E` (approximate LEWITT-style green; not an officially verified brand code).

These are manually reconstructed vector assets based on the approved logo concept. The previously generated PNG branding pack is not included in this pull request.
