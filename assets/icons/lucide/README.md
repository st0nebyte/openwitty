# OpenWitty UI pictograms

These nine SVGs are selected from [Lucide Icons](https://lucide.dev/), fetched from the official `lucide-icons/lucide` repository on 2026-10-18. Their only change is replacing `currentColor` with white for a consistent light stroke in Qt Quick. The complete upstream ISC license, including the MIT notice for Feather-derived `headphones`, is retained in [LICENSE](LICENSE). Source names are the SVG filenames.

`../ui/lowcut.svg` is an independently drawn frequency-curve symbol by the OpenWitty project, used because a generic icon would not clearly communicate a low-cut filter. The OpenWitty logo and existing brand PNGs are unchanged. Mute and other protocol-specific actions remain text labels where that is clearer than an icon.
