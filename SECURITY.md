# Security

Please report security problems **privately** through
[GitHub's private vulnerability reporting](https://github.com/st0nebyte/openwitty/security/advisories/new), not in a
public issue. Relevant areas: the background service's socket (`$XDG_RUNTIME_DIR/openwitty/device.sock`), the udev
rule, files OpenWitty writes, and anything that could change the device's settings without the user's action.

Only the latest release is supported. OpenWitty is unofficial; for LEWITT hardware or firmware issues contact LEWITT.
